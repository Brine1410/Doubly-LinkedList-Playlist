# Doubly Linked List Playlist

A menu-driven Java program that implements a Doubly Linked List
to manage a music playlist.

## Features

- Insert song at first position
- Insert song at last position
- Delete song at first position
- Delete song at last position
- Traverse playlist from first to last
- Traverse playlist from last to first

## Concepts Used

- Doubly Linked List
- Nodes
- Insertion
- Deletion
- Traversal
- Java
